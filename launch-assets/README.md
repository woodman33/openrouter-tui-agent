# TIMMYTUI Product Hunt Launch Assets

This directory contains launch materials, gallery plans, social posts, demo script voiceovers, and checklist definitions for the **TIMMYTUI V2.1** launch campaign.

## 📂 Folder Structure

* `product-hunt-checklist.md` — Complete Product Hunt checklist, parameters, and gallery images roadmap.
* `gallery/` — Target directory for high-res (1270x760) showcase images.
* `screenshots/` — Directory for UI closeups and interface states.
* `video/` — Scripting resources and files for the demo video walk-through.
* `social/` — Prepared launch posts for X (Twitter), LinkedIn, HN, and Reddit.
