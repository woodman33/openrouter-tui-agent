## 🚀 Product Hunt Maker Comment

```text
Hi Product Hunt! 👋

I'm the creator of TIMMYTUI. 

AI agents are expanding rapidly, but they still operate largely inside a black box. You prompt them, they run, and you hope they executed the right terminal command or modified the right file. When things go wrong (or when you need to audit an execution), reviewing raw outputs is difficult.

TIMMYTUI was built to change that by serving as a local-first agent trust console. 

Our V2.1 release is production-demo ready and provides:
1. OpenRouter model selector: Swap models on-the-fly depending on complexity.
2. MCP → CLI Scanner: Audit third-party model context protocols and convert tool calls into local inspectable bash scripts before letting them run.
3. cmux Workspace: Spin up isolated terminal grids to run and monitor agent files.
4. Browser Companion: A synced WebSocket page running on localhost to mirror terminal sessions dynamically.
5. Sealed TIMMY Receipts: An append-only session runner that outputs tamper-evident, hash-bound `.agentrun` files containing a manifest hash you can inspect anytime.

We believe that governance shouldn't slow down local agent utility. Trust the receipt, not the model.

I'd love to hear your feedback on the layout, local logs, and evidence checks! What are you building with agents today?
```

## 📰 Hacker News Show HN Draft

```text
Show HN: TIMMYTUI – Local-first agent trust console with sealed receipts

Hi HN,

Most autonomous agents run commands or make changes to workspaces in ways that are hard to inspect or replay. I wanted a terminal interface that treats agent execution as a governed, verifiable stream.

TIMMYTUI is a local-first terminal dashboard built using React Ink. It connects to OpenRouter for model selection and focuses on visibility and verification:

- MCP → CLI: You paste an MCP server URL, and TIMMY converts the proposed tools into a local inspectable script bundle so you know exactly what tools are being registered and run.
- cmux Workspace: Launch terminal panels side-by-side to view active files and logs.
- Browser Companion: Simple local WebSocket server (port 3001) that mirrors the terminal conversation onto a browser window for a secondary view.
- Sealed TIMMY Receipts: Hashing session logs and manifest parameters into local `.agentrun` records. This creates a tamper-evident, hash-bound ledger of execution.

It is local-first, developer-focused, and production-demo ready.

GitHub: https://github.com/woodman33/openrouter-tui-agent

I'd love to know what you think of the local verification receipts flow!
```
