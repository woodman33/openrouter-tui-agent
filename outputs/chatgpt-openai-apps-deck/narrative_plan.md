# Programmatically Build Apps for ChatGPT / OpenAI Platform

Audience: developers and technical founders deciding whether to build inside ChatGPT with the Apps SDK or build their own product UI on the OpenAI Platform.

Objective: teach both paths, including architecture, code skeletons, local UI testing, dashboard setup, deployment, and submission readiness.

Narrative arc:
1. Start with the product decision: live inside ChatGPT or own the full app surface.
2. Explain the ChatGPT Apps path: MCP server, tools, widget resource, bridge, Developer Mode.
3. Show minimal TypeScript code for server and widget wiring.
4. Explain the OpenAI Platform path: own frontend/backend, Responses API, tools/function calling, streaming.
5. Show minimal Node/Express code for a product UI backed by Responses.
6. Close with deployment, security, review, and a decision checklist.

Slide list:
1. Title and promise
2. The two build paths
3. ChatGPT Apps architecture
4. ChatGPT Apps server code
5. ChatGPT Apps widget code
6. Using the ChatGPT UI
7. OpenAI Platform architecture
8. Platform API code
9. Using the Platform UI and product UI
10. Deployment and submission checklist
